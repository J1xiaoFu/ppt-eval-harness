# Profile location

The active Profile 8.4 defaults and four explicit Profile 8.3 replay contracts
ship inside `ppt_eval.profiles`; this directory no longer contains executable
historical contracts.

To reproduce v1–v7 or pre-registered experiments, check out the immutable Git
tag `archive/v8.3-pre-release` in a separate worktree. Pin that tag together
with the recorded model, prompt, renderer, font bundle, and input artifacts.

# 评测报告模板

## 元数据

| 字段 | 值 |
|---|---|
| EXP ID / Run IDs | `<EXP-...>` / `<RUN-...>` |
| 预注册版本 | `<commit/hash>` |
| 数据 manifest | `<sha256>` |
| Profile / Model / Prompt | `<versions>` |
| 时间窗口 | `<ISO-8601>` |

## 目标与问题

写清主假设、主要指标、门槛和决策用途。禁止在这里加入结果后新增的成功指标。

## 执行过程

描述样本流、盲化/随机化、异常处理、排除、重试和人审。附原始对象存储位置与审计事件范围。

## 证据与结果

| 指标 | target | estimate | 95% CI | slice | verdict |
|---|---:|---:|---:|---|---|
| `<metric>` | `<planned>` | `<observed>` | `<low, high>` | `<all>` | `<pass/fail>` |

同时报告 Oracle ERROR/降级/覆盖/延迟/成本；不可只报告成功样本。

## 失败案例

列出 case/run ID、机器证据、人工结论、根因、是否系统性、处置与新测试 ID。图片只放定位证据，
不暴露业务敏感信息。

## 决策与取舍

明确接受、拒绝、继续 Shadow 或回滚；区分观察事实、因果解释和后续假设。

## 风险与限制

报告样本量、域外推、人工上限、数据污染、供应商漂移和未覆盖场景。

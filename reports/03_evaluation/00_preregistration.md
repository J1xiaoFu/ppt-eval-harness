# 实验预注册 v1

## 研究问题

1. 自动评测是否与训练后人工金标一致？
2. 高置信硬门禁能否低误拦且低严重误放行？
3. 评分是否对受控缺陷方向正确、局部、单调并可重复？
4. 四场景专项故障时，本体报告是否始终保留？

## 数据与冻结

在任何冻结集结果可见前锁定：数据 manifest hash、父子分组切分、Rubric/Profile/Prompt/模型/字体/
渲染器版本、排除规则和随机种子。冻结集永不用于权重、阈值或 Prompt 调整；失败分析进入工作池新样本。

## 主指标与门槛

| 指标 | 统计方法 | planned target | observed |
|---|---|---:|---|
| 客观人标一致性 | Krippendorff α / bootstrap 95% CI | α≥0.80 | pending |
| 自动-人工偏好一致 | blind pairwise accuracy | ≥80% | pending |
| 高置信自动拦截精度 | Wilson 95% lower bound | ≥98% 点目标并报告下界 | pending |
| 严重缺陷误放行 | Wilson 95% upper bound | <1% | pending |
| 门禁重复一致性 | 三次重复完全一致率 | ≥99% | pending |

次指标：ICC、Spearman/Kendall、Brier/ECE、缺陷定位 F1、覆盖率、P95 延迟、成本、切片误差。

## 样本量与切片

正式样本量在试点方差/基准率后用功效分析确定，不凭固定数字宣称充分。至少报告场景、语言、页数、
模板、生成模型、输入格式和 OOD 切片；小切片仅报告区间，不作肯定性结论。

## 排除与缺失

- 输入损坏不是统计排除，而是可交付性标签。
- Oracle `ERROR` 不计零分，单独报告错误率和降级率。
- 只在预注册的合规/重复/数据泄漏条件下排除；每个排除保留 case ID 与原因。
- 多重比较使用 Holm 校正；探索性分析明确标注，不改变主结论。

## 停止与发布规则

任一安全事件、Manifest 缺失或冻结泄漏立即停止。只有全部主门槛、切片风险审查、Shadow 和业务指标
同时通过才能进入 5% 灰度；不能用平均分抵消严重误放行。

# 威胁模型、FMEA、容量与 SLO

## 信任边界

PPTX、备注、隐藏对象、嵌入媒体和来源材料均不可信；外部模型/检索是半可信供应商；人工复核是
授权主体但仍可能误操作。领域存储、Profile Registry 和 append-only Audit Store 为高信任区。

## Threat Model

| 威胁 | 攻击路径 | 控制 | 验证 |
|---|---|---|---|
| 压缩炸弹/路径穿越 | OOXML 解包 | 条目数、膨胀率、大小、规范路径、沙箱 | 恶意 fixture |
| 宏/外链/嵌入对象 | 关系与 OLE | 禁执行、禁外联、隔离、显式报告 | 静态扫描 |
| 提示注入 | 页面/备注“忽略规则” | 内容仅作 user evidence；严格 JSON；工具白名单 | 注入挑战集 |
| 隐藏文字投机 | 透明/页外/极小文字 | 可见性模型+对象树与像素交叉 | 变形测试 |
| 数据泄露 | 外部 Judge | 脱敏、字段最小化、供应商路由 | DLP 与审计 |
| Profile 篡改 | 权重/Prompt 更新 | 签名、RBAC、双人审批、版本不可变 | 权限测试 |
| 审计删除 | 覆盖事件 | append-only/WORM、hash chain、`supersedes` | 回放测试 |

## FMEA

| 失效模式 | 影响 | S/O/D | RPN | 措施 | 降级 |
|---|---|---|---:|---|---|
| 主渲染失败 | 视觉指标缺失 | 8/3/2 | 48 | 重试+备用渲染，保留解析 | BASE_ONLY/REVIEW |
| Scene Judge 超时 | 无专项结论 | 6/5/2 | 60 | 熔断、预算、异步重试 | S_base only |
| OCR 漂移 | 文本定位偏差 | 6/4/5 | 120 | 结构文本优先、抽样校准 | 降置信/人审 |
| 重复惩罚 | 总分过低 | 8/2/3 | 48 | defect 去重编译器 | Profile 拒绝 |
| 错误转零分 | 误拦截 | 9/2/2 | 36 | 状态类型隔离 | REVIEW |
| 字体缺失 | 版式误判 | 5/6/3 | 90 | 版本化字体包、差分阈值 | Compatibility evidence |
| Outbox 堵塞 | 飞轮信号延迟 | 4/3/2 | 24 | 重放、lag 告警 | 评测不阻塞 |

`S/O/D` 分别为严重度、发生度、探测难度（1–10）；RPN 用于排优先级，不代替安全门禁。

## 容量与成本模型

单任务成本估算：`C = pages*(C_render + C_ocr + C_vlm) + tokens*C_llm + C_storage`。
队列按 parser/render/judge 分池，租户和场景设并发、页数、Token、金额四重预算。20 页为基准，
超过 100 页进入大文件队列；超过硬上限直接拒绝并提供理由。

## SLO（待压测确认）

| SLI | 目标 | 告警 |
|---|---:|---:|
| API 可用性 | 99.9% / 月 | 5m burn-rate |
| 快速层 20 页 P95 | ≤30s | >35s 连续 15m |
| 完整层 P95 | ≤5min | >6min 连续 30m |
| 本体报告保留率 | 100% | 任一专项故障吞报告 |
| 审计 Manifest 完整率 | 100% | 任一关键字段缺失 |
| 队列任务丢失 | 0 | 任一确认丢失 |

## 发布与回滚

Artifact、Profile 和 Adapter 分别版本化。灰度 5%→25%→100%，每阶段比较质量、返工、成本和延迟。
回滚切回上一签名 Profile/镜像，不覆盖新运行；失败版本仍保留可审计记录。
